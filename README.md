# hr-analytics-dashboard-excel
**Project Overview**
This project is an HR Analytics Dashboard built using Excel. It helps to analyze employee data and understand important HR metrics like attrition, employee count, salary, age, and job roles.
The dashboard gives a clear visual view of workforce data, which helps in making better HR decisions.
________________________________________
**Key Insights**
•	Total employees: 69 
•	Attrition count: 15 
•	Active employees: 54 
•	Attrition rate: 21.74% 
•	Average age: 38 
________________________________________
**Dashboard Features**
•	Employee analysis by gender 
•	Attrition by job role 
•	Attrition based on education 
•	Attrition by age group 
•	Attrition by marital status 
•	Department-wise analysis 
•	Filters for better data exploration 
________________________________________
**Tools Used**
•	Microsoft Excel 
•	Pivot Tables 
•	Pivot Chart
•	Charts and Graphs 
•	Slicers and Filters 
________________________________________
**Conclusion**
This project helps to understand basic HR analytics using Excel. It shows how employee data can be analyzed to find patterns in 
attrition, demographics, and job roles. These insights can help HR teams make better decisions to improve employee retention.
